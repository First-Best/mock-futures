# 24시 모의선물

가상 돈(사이버머니)으로 롱·숏 레버리지 거래를 연습하는 모의 거래소예요. 실제 돈은 오가지 않아요.

- 시세: [Hyperliquid](https://hyperliquid.xyz) 공개 API와 [OKX](https://www.okx.com) 공개 API(키 없음). 코인 6개와 주식·지수·ETF·원자재·환율 등 230여 개 종목. 주식 쪽은 [trade[XYZ]](https://trade.xyz) 같은 Hyperliquid 위 시장과 OKX 주식 선물 가격이라 주말에도 움직여요. 정규장이 닫힌 시간에는 거래자들이 만든 가격이에요.
- 매달 1일 0시(기기 시간)에 가상 월급 10,000 USDC가 들어와요. 이익과 손실은 계속 이어져요.
- 실제 DEX처럼 종목마다 포지션 하나, 교차(Cross)·격리(Isolated) 증거금을 고를 수 있어요.
- 지정가(예약) 주문, 차트 위 익절·손절·예약 가격 줄(점선·실선). 줄을 잡고 끌어서 익절·손절·예약가를 옮기고, 격리 청산 줄을 끌어 증거금을 넣고 뺄 수 있어요.
- 처음부터 다시 하기는 없어요. 돈을 다 잃으면 다음 달 월급을 기다려요.
- **순위**: 아이디·비밀번호로 가입하면 모두의 수익률 순위가 실시간으로 공개돼요. 가입하지 않으면 기록은 각자 브라우저 안에만 있어요.
- **로그인·동기화**: 같은 아이디로 로그인하면 휴대폰·컴퓨터·다른 브라우저 어디서나 같은 기록이에요. 기록이 바뀌면 서버에 저장되고 다른 기기는 다시 열 때 가져와요. 비밀번호는 서버에 bcrypt로 암호화해 저장해요. "계정 지우기"로 서버 기록을 지울 수 있어요.
- **서버 자동 체결·알림**: 앱을 닫아 둬도 서버가 1분마다 예약 주문·익절·손절·청산·월급을 확인해 처리하고, 알림을 켠 기기로 알려 줘요(웹 푸시). 아이폰은 홈 화면에 추가한 앱에서만(iOS 16.4 이상).
- **앱으로 설치**: 안드로이드·컴퓨터 크롬은 화면 위 "앱으로 설치" 버튼(또는 메뉴 ⋮ → 앱 설치), 아이폰은 사파리 공유 버튼 → 홈 화면에 추가. 홈 화면 아이콘으로 주소창 없이 열려요.
- 서버 설정: `supabase.sql`(표·함수), `supabase/functions/engine/index.ts`(자동 체결·알림), `supabase-engine.sql`(1분마다 깨우기).
- 화면은 `index.html` 하나로 돌아가요. 설치용 파일은 `manifest.webmanifest`, `sw.js`(서비스 워커), `icons/`.
